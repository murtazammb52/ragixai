Boundaries

Project Scope

Explicit in-scope and out-of-scope boundaries prevent scope creep and keep the project focused on what matters.

✅

In Scope

✓ RAG pipeline (ingest → chunk → embed → retrieve → rerank → generate)
✓ SEC EDGAR document ingestion: 10-K, 10-Q, 8-K filings via EDGAR API + local corpus
✓ RAGAS evaluation framework with all 5 core metrics
✓ A/B comparison of at least 7 RAG configurations
✓ Local demo (ChromaDB + sentence-transformers) + AWS stretch deployment
✓ 8 Claude Code custom slash commands (.md skill files)
✓ Chat UI with citation display
✓ Automated evaluation report generation
✓ Security: IAM roles, VPC isolation, encryption at rest
✓ Cost analysis and ROI calculation
🚫

Out of Scope

✗ Fine-tuning foundation models (using PEFT/LoRA on domain data)
✗ Multi-tenant / per-user data isolation (single org deployment)
✗ Real-time document sync (scheduled batch ingestion only)
✗ Image/video content understanding (text documents only)
✗ Conversational memory / multi-turn session context
✗ User authentication & SSO integration (mocked for demo)
✗ Mobile application (web only)
✗ Multilingual query support (English only)
✗ Production SLA / 24-7 on-call operations
✗ Custom embedding model training from scratch

Definition of Done

Key Success Metrics

These are the specific, measurable criteria that define success. If we hit all of these, the project is a success — no ambiguity.

≥ 0.85
Average RAGAS Score (Optimal Config)
Weighted average of Faithfulness, Answer Relevancy, and Context Precision for our chosen Config E, evaluated on the full 500-question synthetic dataset.
≤ 3.0s
p95 Query Latency
95th percentile end-to-end latency from query submission to final answer — under 3 seconds. Measured under simulated load of 10 concurrent queries.
7 configs
Configurations Compared
At least 7 distinct RAG configurations evaluated with RAGAS — varying embedding model, retrieval strategy, and reranking approach — with a clear winner justified by data.
100%
Citation Coverage
Every generated answer includes at least one source citation pointing to a real document in the knowledge base. Zero uncited factual claims in the output.
