Design Decisions

Key Technical Decisions

We will evaluate these options and measure their impact on pipeline quality. Each component has multiple candidates that we test head-to-head.

1. 🔢 Embedding Model Options

Model Dimensions MTEB Score Speed (tok/s) Cost / 1M tok Notes
Amazon Titan Embed v2 1024 68.2 ~4,000 $0.02 Native AWS, lowest cost
Cohere Embed v3 1024 74.8 ~3,500 $0.10 High MTEB, multilingual
OpenAI text-embedding-3-large 3072 74.9 ~2,500 $0.13 Highest dims, benchmark

Evaluation Plan: We will run each embedding model through the full RAGAS suite and select based on measured Context Precision, Context Recall, and cost-per-query on our actual evaluation datasets.

2. 🗄️ Vector Store Options

Store Hosting Hybrid Search Latency (p95) Enterprise SLA Notes
AWS OpenSearch Managed AWS ✓ k-NN + BM25 ~35ms 99.9% uptime Stays in AWS ecosystem
ChromaDB (EC2) Self-hosted Partial ~80ms No SLA Free tier compatible
FAISS (EC2) Self-hosted Dense only ~20ms No SLA Fastest, no managed ops

Evaluation Plan: We will benchmark retrieval latency and hybrid search quality across these options on the MS MARCO v2.1 and SQuAD 2.0 datasets before selecting the final store.

4. 📈 Re-ranking Options

Without Re-ranking

Top-k results returned directly from ANN (approximate nearest neighbor) search. Fast but approximate — vector similarity doesn't perfectly correlate with answer quality.

Context Precision
0.68
Faithfulness
0.72

With Cross-Encoder Re-ranking

Cross-encoder jointly encodes query+chunk and computes a direct relevance score. Much more accurate than bi-encoder similarity alone. Adds ~150ms but significantly improves quality.

Context Precision
0.84
Faithfulness
0.89
