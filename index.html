The Project

What We're Building

Three interconnected systems working in harmony to solve the enterprise knowledge crisis

🧠

RAG Pipeline

A production-ready Retrieval-Augmented Generation pipeline that ingests, chunks, embeds, and retrieves enterprise documentation with semantic precision.

  • Semantic + hybrid retrieval
  • Cross-encoder re-ranking
  • Citation-grounded answers
  • Multi-source ingestion
📊

Evaluation Framework

A rigorous RAGAS-based evaluation system comparing multiple configurations across faithfulness, relevancy, context precision, and latency metrics.

  • 6 RAGAS metrics tracked
  • A/B configuration testing
  • Automated scoring pipeline
  • Baseline vs target comparison
☁️

AWS Integration

Enterprise-grade infrastructure on AWS using Bedrock for LLM inference, OpenSearch for vector storage, and Step Functions for orchestration.

  • Amazon Bedrock (Claude)
  • OpenSearch vector store
  • Textract PDF parsing
  • Step Functions workflow
