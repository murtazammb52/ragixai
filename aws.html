Service Roles

Each Service's Specific Role

10 services, each carefully chosen for its specific strength in the RAGixAI architecture.

🪣
Amazon S3
Storage · Orange

Primary document repository. All raw source files (PDFs, exported markdowns) are stored here before processing. Also stores processed chunk metadata as JSON objects. Lifecycle policies auto-expire old versions.

🔍
Amazon Textract
ML · Document AI · Blue

ML-powered document parsing service. Extracts text from PDFs including scanned images, tables, and forms with high accuracy. Handles multi-column layouts and complex enterprise document formats that simple PDF parsers fail on.

λ
AWS Lambda
Serverless · Compute · Orange

Serverless functions handle two roles: (1) the ingestion pipeline — chunking and embedding generation triggered by S3 events, and (2) the query handler — executing retrieval, reranking, and Bedrock calls. Auto-scales to zero when idle.

🔄
AWS Step Functions
Orchestration · Pink

Visual workflow orchestration for the ingestion pipeline. Defines the state machine: S3 trigger → Textract → chunk → embed → index → complete. Provides automatic error handling, retries, and execution history for debugging.

🧠
Amazon Bedrock
AI/ML · Foundation Models · Blue

The AI brain of RAGixAI. Provides access to Claude 3.5 Sonnet for answer generation AND Cohere Embed v3 for document and query embedding — all through a single AWS API with unified security, logging, and billing.

🔎
Amazon OpenSearch
Search · Vector DB · Blue-Green

The heart of retrieval. k-NN plugin enables approximate nearest-neighbor vector search at scale. Simultaneously maintains an inverted text index for BM25 sparse retrieval. Managed service with automated backups and failover.

🌐
Amazon API Gateway
API · REST · Purple

Exposes a RESTful API for the frontend and enterprise integrations. Handles authentication via Cognito, rate limiting, CORS, and request/response transformation. WebSocket support for streaming responses.

🖥️
AWS Amplify
Frontend · Hosting · Orange

Hosts the React-based chat interface. Git-integrated CI/CD deploys on every push. CloudFront CDN ensures sub-100ms global load times. The /deploy-aws skill handles full deployment automatically.

📊
Amazon CloudWatch
Monitoring · Alerts · Red-Orange

Monitors all services in real time. Custom dashboards track: query latency (p50/p95/p99), retrieval hit rate, Bedrock token usage and cost, Lambda cold starts, and OpenSearch cluster health. Alarm triggers auto-scaling.

🔑
AWS IAM
Security · Governance · Red

Zero-trust security with least-privilege IAM roles for every service. Lambda roles can only call Bedrock and OpenSearch — nothing else. All cross-service communication is role-based, not key-based. VPC isolation for sensitive components.

Why Amazon Bedrock?

🧠

The Single Pane of Glass for Foundation Models

Amazon Bedrock provides a unified API to access Claude 3.5 Sonnet, Cohere Embed v3, and other models — without managing infrastructure, without separate billing relationships, and without data leaving the AWS account.

🔒
Enterprise Security
Data never used for model training. VPC endpoints. SOC 2 Type II compliant.
🔄
Model Flexibility
Swap Claude for Titan or Llama with one config change. No code rewrite required.
📦
Zero Infra
No GPU instances to manage. Serverless inference. Pay per token, not per hour.

Enterprise Trust

Security & Compliance

Enterprise-grade security baked in from day one — not bolted on after.

🔐

Encryption Everywhere

AES-256 at rest for all S3 objects and OpenSearch indices. TLS 1.3 for all data in transit. KMS-managed keys with automatic annual rotation.

🏰

VPC Isolation

OpenSearch and Lambda run in private VPC subnets. No public internet access. All AWS service communication via VPC endpoints to avoid data leaving the private network.

🔑

Least-Privilege IAM

Each Lambda function has an IAM role with exactly the permissions it needs — nothing more. Service-to-service communication uses IAM roles, never static access keys.

📋

Full Audit Trail

AWS CloudTrail logs every API call. CloudWatch captures every query with user ID, query text, retrieved chunks, and response. Full 90-day audit history for compliance.

🚫

No Training on Your Data

Amazon Bedrock guarantees that your prompts and completions are never used to train or improve foundation models. Your enterprise data stays your enterprise data.

✅

Compliance Posture

AWS infrastructure is SOC 2 Type II, ISO 27001, GDPR, HIPAA-eligible, and FedRAMP Moderate certified. RAGixAI inherits these certifications for your compliance reports.
