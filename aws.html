Service Roles

Each Service's Specific Role

10 services, each chosen for its specific strength — and every one is free.

🪣
Amazon S3
Storage 5 GB free · 12 months

Primary document repository. All raw source files (PDFs, exported markdowns) are stored here before processing. Also stores processed chunk metadata as JSON objects. Free tier: 5 GB storage, 20,000 GET requests, 2,000 PUT requests per month.

🔍
Amazon Textract
Document AI 1,000 pages/month free · 12 months

ML-powered document parsing. Extracts text from PDFs including scanned images and tables. Our project ingestion volume (research papers, evaluation datasets) stays well within the 1,000 pages/month free allowance.

λ
AWS Lambda
Serverless 1M requests/month · Always Free

Handles two roles: (1) ingestion pipeline — chunking and embedding triggered by S3 events, and (2) query handler — executing retrieval and reranking. 1M free requests/month and 400,000 GB-seconds compute — Always Free, no expiry.

🔄
AWS Step Functions
Orchestration 4,000 transitions/month · Always Free

Orchestrates the ingestion state machine: S3 trigger → Textract → chunk → embed → index → complete. 4,000 state transitions/month free (Always Free tier). Provides error handling, retries, and execution history.

🖥️
Amazon EC2 t2.micro
Compute 750 hours/month · 12 months

Hosts ChromaDB or FAISS as the vector store. A t2.micro (1 vCPU, 1 GB RAM) is sufficient for our project corpus size. 750 hours/month = effectively always-on for a single instance. Replaces Amazon OpenSearch, which has no free tier.

📋
Amazon DynamoDB
NoSQL DB 25 GB storage · Always Free

Stores document metadata (source URL, ingestion timestamp, chunk count, embedding model used) and chat history. 25 GB storage + 25 WCU + 25 RCU free — Always Free, no expiry. More than sufficient for our evaluation runs.

🌐
Amazon API Gateway
API 1M HTTP calls/month · 12 months

Exposes the REST API for the chat frontend. Handles CORS, rate limiting, and request routing to Lambda. 1 million HTTP API calls per month free (12 months) — vastly more than our demo usage requires.

🖥️
AWS Amplify
Frontend 1K build mins + 5 GB + 15 GB BW · 12 months

Hosts the React-based chat interface with Git-integrated CI/CD. Free tier: 1,000 build minutes, 5 GB storage, 15 GB bandwidth per month. The /deploy-aws skill handles full deployment automatically.

📊
Amazon CloudWatch
Monitoring 10 metrics + 10 alarms · Always Free

Monitors all services in real time. Custom dashboards track: query latency (p50/p95/p99), retrieval hit rate, Lambda cold starts. Basic monitoring + 10 custom metrics + 10 alarms = Always Free — no charges for our project.

🔑
AWS IAM
Security Always Free

Zero-trust security with least-privilege IAM roles for every service. Lambda roles can only call their specific target services — nothing else. All cross-service communication is role-based, never key-based. Always free — no usage charges ever.

LLM Strategy

Free-Tier Language Model

Amazon Bedrock is not free tier — we use HuggingFace Inference API instead, with an optional paid upgrade path.

🤗
HuggingFace Inference API
Primary — Free Tier

HuggingFace provides free serverless inference for open-source models. We use mistralai/Mistral-7B-Instruct-v0.2 or google/flan-t5-xl — both available on the free tier with no credit card required.

  • No AWS account needed for LLM calls
  • Mistral-7B: strong instruction following, ~4K context
  • Flan-T5-XL: fast, optimized for QA tasks
  • Free API key — just create a HuggingFace account
🧠
Amazon Bedrock
Optional Upgrade — Pay-Per-Use

Amazon Bedrock is not free tier — it charges per token. However, if upgraded for final demo, Claude Haiku costs only ~$0.0008/1K tokens — roughly $0.001 per typical query. Optional for the final production demo.

Note: For all development, testing, and capstone evaluation, we use HuggingFace free tier. Bedrock is documented as an optional upgrade path only.

Architecture Decisions

What Replaces Paid Services

We explicitly chose not to use three popular AWS services because they have no free tier.

❌
Amazon OpenSearch Service
NOT free tier — minimum ~$0.10/hour

A managed OpenSearch cluster costs at minimum $72–$150/month even on the smallest instance. There is no free tier option.

→
✅
ChromaDB / FAISS on EC2 t2.micro
Free for 750 hours/month (12 months)

Self-hosted ChromaDB or FAISS on the free t2.micro instance. Handles dense vector similarity search for our project-scale corpus with no cost.

❌
Amazon Bedrock
NOT free tier — pay per token

Bedrock charges per token used. Claude Haiku costs ~$0.0008/1K tokens — inexpensive but not free. For unlimited development iteration, a free alternative is better.

→
✅
HuggingFace Inference API
Free — rate-limited serverless inference

Mistral-7B-Instruct-v0.2 or Flan-T5-XL via HuggingFace free tier. Sufficient for all development and evaluation runs. Optional: upgrade to Bedrock Claude Haiku for final demo.

❌
Amazon Kendra
NOT free tier — $810/month minimum

Amazon Kendra's Developer edition costs $810/month. There is no free tier. This is entirely outside our project budget and unnecessary given our RAG implementation.

→
✅
Custom RAG Pipeline (our system)
Free — built by us using Lambda + EC2

Our custom-built retrieval pipeline (Lambda + ChromaDB + BM25) provides equivalent or better performance for our use case, with full transparency and no vendor lock-in.

After Free Tier

Optional Upgrade Path

What happens when the 12-month free tier expires — an optional paid configuration for production use.

For this capstone project: We operate entirely within free tier limits. The upgrade path below is informational only — documented to show we understand the production cost structure.

🔍

Vector Store Upgrade

Replace EC2-hosted ChromaDB with Amazon OpenSearch (t3.small, ~$50/month) for managed failover and larger index sizes when corpus exceeds EC2 capacity.

Trigger: >50K documents or SLA needed
🧠

LLM Upgrade

Switch from HuggingFace free tier to Amazon Bedrock Claude Haiku (~$0.001/query) for lower latency, higher reliability, and enterprise security guarantees.

Cost: ~$60/month at 2,000 queries/day
⚡

Compute Upgrade

Upgrade EC2 from t2.micro to t3.medium (~$30/month) for higher concurrent query throughput and larger in-memory vector indices.

Trigger: p95 latency exceeds 3s target

Post-free-tier estimate: ~$150/month — for a small production deployment with managed OpenSearch, Bedrock Claude Haiku, and t3.medium EC2. Compare this to $4,560/year vs a $14.2M/year productivity problem — still a 3,000× ROI.

Security

Security & Access Control

Security practices apply even on free tier — good habits from day one.

🔐

Encryption at Rest

AES-256 for all S3 objects and DynamoDB tables. EBS volume encryption enabled on EC2 t2.micro. No plaintext data persisted anywhere.

🔑

Least-Privilege IAM

Each Lambda function has an IAM role with exactly the permissions it needs. Service-to-service communication uses IAM roles, never static access keys. IAM is always free.

🚫

No Training on Data

HuggingFace Inference API does not use submitted prompts for training. For the optional Bedrock upgrade, Amazon guarantees no model training on your data either.
