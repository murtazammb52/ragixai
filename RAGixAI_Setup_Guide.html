1 Prerequisites — Install Once

These are installed once and never need to be repeated.

1.1 — Ollama (Local LLM Runtime)

Ollama runs LLMs locally. Download and install the Windows installer:

# 1. Download OllamaSetup.exe from https://ollama.com
# 2. Run the installer — it installs as a background Windows service
# 3. Verify it is running:
ollama list
# Should show an empty table (no models yet) — that is fine

1.2 — Anaconda (Python Environment)

Already installed at C:\Users\murta\anaconda3. No action needed.

1.3 — Pull the LLM Model

Pull the 1B model — small enough for your MX450 GPU (2GB VRAM):

ollama pull llama3.2:1b
# Downloads ~650 MB — do this once. Takes 1–5 min on a good connection.
# Verify:
ollama list
# Expected output:
# NAME               ID         SIZE    MODIFIED
# llama3.2:1b        ...        1.3 GB  ...
✓ Prerequisites complete Ollama is installed, running as a Windows service, and the model is downloaded. You only need to do this section once ever.

2 First-Time Python Environment Setup

This section sets up the ragixai conda environment with all required packages. Do this once. After the environment exists, skip to Section 3.

⚠ Important — Run all commands from the project root Open Anaconda Prompt (or any terminal with conda activated) and cd to D:\code\ragixai before running any command below. 
# Open: Start Menu → Anaconda Prompt (Anaconda3)
# Then navigate to the project folder:
cd D:\code\ragixai

2.1 — Create the Conda Environment

# Creates a Python 3.11 environment named "ragixai"
# Stored at: D:\envs\ragixai  (on D drive to save C drive space)
conda create --prefix D:\envs\ragixai python=3.11 -y

# Activate it:
conda activate D:\envs\ragixai
# Your prompt should now show: (D:\envs\ragixai) ...

2.2 — Install Python Dependencies

# Install all required packages (takes 5–15 min first time):
pip install -r requirements.txt
# This installs: fastapi, chromadb, sentence-transformers, ollama,
# rank-bm25, ragas, langchain, torch, uvicorn, and more.
✓ Environment ready The ragixai conda environment is now set up. You never need to recreate it unless you explicitly delete it.

Step 1 — Ingest SEC EDGAR Filings

Downloads 10-K annual reports directly from the SEC EDGAR API for the specified companies.

# Download 10-K filings for Apple and Microsoft (recommended starting set):
python scripts/run_ingest.py --companies AAPL,MSFT

# Or download for all default companies (AAPL, MSFT, AMZN, GOOGL, META, NVDA, TSLA, JPM, BAC, WMT):
python scripts/run_ingest.py

# Files are saved to: data/raw/edgar/AAPL/, data/raw/edgar/MSFT/, etc.
# A manifest.json tracks all downloaded filings.
Common flags --companies AAPL,MSFT,GOOGL — specific companies only
--max-filings 3 — limit to 3 filings per company (faster for testing)
--years 2023,2024 — specific years only

Step 2 — Chunk the Documents

Splits the raw filings into overlapping text segments for retrieval.

# Use recursive chunking (recommended — best balance of quality and speed):
python scripts/run_chunk.py --strategy recursive

# Output saved to: data/processed/chunks/chunks_recursive.jsonl
# Other strategies: "fixed" (token-based) or "semantic" (similarity-based)

Step 3 — Build the Vector Index

Embeds all chunks using sentence-transformers and stores them in ChromaDB.

# Build the index (downloads embedding model ~90MB on first run):
python scripts/run_build_index.py

# To completely reset and rebuild from scratch, add --reset:
python scripts/run_build_index.py --reset

# Index is saved to: data/chroma_db/
# When complete you should see: "Indexed N chunks into ragixai_local"
✓ Data pipeline complete ChromaDB now contains all embedded document chunks. The BM25 sparse index is built automatically when the server starts.

4 Daily Startup — Every Session

Follow these steps every time you open your laptop and want to use RAGixAI.

Quick checklist — do these in order
  • Ollama service is running (usually auto-starts on Windows login)
  • Anaconda Prompt is open and in the project folder
  • Conda environment is activated
  • FastAPI server is started

Step A — Verify Ollama is Running

# Open any terminal (not necessarily Anaconda Prompt) and run:
ollama list
# Expected: shows llama3.2:1b in the list
# If you get "connection refused": open Start Menu and search "Ollama" to launch it

# Also verify the model is available:
ollama ps
# Will show active model if one is loaded (may be empty until first query — that's fine)

Step B — Open Project in Anaconda Prompt

# Start Menu → Anaconda Prompt (Anaconda3)
# Then:
cd D:\code\ragixai
conda activate D:\envs\ragixai
# Prompt now shows: (D:\envs\ragixai) D:\code\ragixai>

Step C — Start the FastAPI Server

# Start the server (keep this terminal open — do not close it):
uvicorn backend.main:app --host 0.0.0.0 --port 8000

# You will see startup messages like:
# INFO:     RAGixAI starting up...
# INFO:     BM25 index built with 680 documents
# INFO:     Server ready — Chat UI: http://localhost:8000/chat
# INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
⚠ Keep the terminal open The server runs in the foreground. If you close the terminal, the server stops. Open a second terminal for any other commands.

Step D — Open the Chat UI

Open your browser and go to:

http://localhost:8000/chat/

You should see the RAGixAI chat interface. Type any question about Apple or Microsoft financials.

6 Running a Test Query (CLI)

You can test the RAG pipeline from the command line without the browser:

# Make sure the server is running first (Step C above), then in a NEW terminal:
conda activate D:\envs\ragixai
cd D:\code\ragixai

# Run a query using Config A (dense retrieval, no reranking):
python scripts/run_query.py --question "What were Apple's total net sales in FY2024?"

# Run using Config D (hybrid retrieval + reranking — best quality):
python scripts/run_query.py --question "What is Microsoft's cloud revenue?" --config config_d

7 RAG Configuration Modes

Config Retrieval Reranking Best For
Config A Dense (ChromaDB cosine) None Baseline / fastest
Config B BM25 (keyword) None Exact term matching
Config C Hybrid (BM25 + Dense) None Good general recall
Config D Hybrid (BM25 + Dense) Cross-encoder Best quality (recommended)
Config E Cohere Embed v3 Cross-encoder Best embeddings (needs API key)
Config F Dense Cross-encoder Dense + reranked
Config G BM25 Cross-encoder Keyword + reranked

8 Troubleshooting

Server won't start — "Address already in use"

# Find and kill the process using port 8000:
# In Anaconda Prompt (Windows):
netstat -ano | findstr :8000
# Note the PID number in the last column, then:
taskkill /F /PID <PID_NUMBER>
# Then restart the server normally.

Ollama not responding / connection refused

# Check if Ollama service is running:
ollama list
# If it errors: Start Menu → search "Ollama" → click to launch
# Or: open a new terminal and run "ollama serve" to start manually

Slow responses (over 2 minutes)

Root cause Your GPU (NVIDIA MX450) has 2GB VRAM. If the model doesn't fit fully in VRAM, it falls back to CPU which is very slow. Always use llama3.2:1b, not the 3B model. 
# Confirm the .env file has the 1B model:
# Open D:\code\ragixai\.env and check:
OLLAMA_MODEL=llama3.2:1b

# Also confirm Ollama is using GPU:
ollama ps
# Look for "GPU" or "CPU/GPU" in the PROCESSOR column

ChromaDB is empty (0 documents)

# Re-run the full data pipeline (Section 3):
python scripts/run_ingest.py --companies AAPL,MSFT
python scripts/run_chunk.py --strategy recursive
python scripts/run_build_index.py --reset

Chat UI shows blank page or 404

# Make sure you have the trailing slash:
# ✗  http://localhost:8000/chat
# ✓  http://localhost:8000/chat/
# Also confirm the server is running (Step C)

Import errors when starting server

# Make sure the ragixai conda environment is activated:
conda activate D:\envs\ragixai
# Then try starting the server again.
# If specific packages are missing:
pip install -r requirements.txt
