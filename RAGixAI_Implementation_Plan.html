RAGixAI — Implementation Plan

End-to-end RAG system for SEC EDGAR financial intelligence · Generated 2026-05-01

Context

The repo currently contains only a static documentation website and PPTX generator — no actual backend code exists. We are building the full RAG system from scratch: a Python FastAPI backend (the RAG engine) + a new chat.html page (the chat UI) that fits the existing dark glass-morphism design. The system answers SEC financial queries by retrieving from ingested EDGAR filings stored in a local ChromaDB vector store.

Architecture Decisions

Server
One FastAPI server (port 8000) — serves both /api/* and /chat static UI
LLM
Ollama — fully local, no API key needed (Llama 3.2 / Mistral)
Embeddings
sentence-transformers/all-MiniLM-L6-v2 (local, free) · Cohere v3 optional
Vector Store
ChromaDB — disk persistence at data/chroma_db/
Sparse Retrieval
BM25 via rank_bm25 — in-memory, rebuilt from ChromaDB on startup
Reranker
cross-encoder/ms-marco-MiniLM-L-6-v2 (local, ~85MB)
Initial Corpus
10 companies (AAPL, MSFT, AMZN, GOOGL, META, NVDA, TSLA, JPM, BAC, WMT) via HuggingFace eloukas/edgar-corpus
Frontend
Single chat.html matching dark glass-morphism site design — vanilla JS, no build step

Data Flow

Offline Pipeline (run once)

HuggingFace eloukas/edgar-corpus (streaming, 10 companies)
  → pipeline/ingest.py    → data/raw/edgar/*.txt
  → pipeline/chunker.py   → data/processed/chunks/*.jsonl
  → pipeline/embedder.py  → vectors in memory
  → pipeline/indexer.py   → ChromaDB (data/chroma_db/)

Embeddings are created once at ingest time and stored. BM25 index rebuilt from ChromaDB on startup (~2s for 10 companies).

Online Pipeline (per query, ~2–3s)

User question
  → embed query (1 forward pass, ~50ms)
  → Dense ANN (ChromaDB) + BM25 → RRF merge → top-20 chunks
  → CrossEncoder rerank → top-5 chunks
  → Ollama (local LLM) + prompt template → answer + [1][2][3] citations
  → JSON response to chat.html

Evaluation (RAGAS + LLM-as-Judge)

DatasetSizePurpose
FinanceBench (PatronusAI/financebench)150 QA pairsGold standard — expert-annotated from real SEC filings
RAGAS Testset~100 QA pairsAuto-generated from ingested EDGAR docs

RAGAS uses an LLM internally as judge (scores Faithfulness & Answer Relevancy). Configured to use Ollama locally — no external API needed. Six metrics tracked: Faithfulness, Answer Relevancy, Context Precision, Context Recall, Answer Correctness, Response Latency (p95).

Pre-requisites

  1. Install Ollama from https://ollama.com → run ollama pull llama3.2
  2. Create a virtual env: python -m venv venv && venv\Scripts\activate
  3. Install deps: pip install -r requirements.txt
  4. Copy .env.example to .env, set OLLAMA_MODEL=llama3.2
  5. Run /ingest-docs then /build-index before first query
  6. (Optional — Config E) Add COHERE_API_KEY in .env — free tier at cohere.com
