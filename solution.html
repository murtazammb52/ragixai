The Technology

What is RAG?

Retrieval-Augmented Generation combines the precision of search with the fluency of large language models

1
🔍

Retrieve

Find the most semantically relevant chunks from your knowledge base using vector similarity

2
📋

Augment

Inject the retrieved context into the LLM's prompt so it has authoritative information to reference

3
💬

Generate

LLM generates a grounded answer using only the retrieved context — with source citations included

Key Insight: RAG eliminates hallucinations by forcing the LLM to answer only from retrieved documents. If the answer isn't in the KB, the system says so.
Architecture

Our Solution Architecture

Five integrated components working together to deliver enterprise-grade knowledge access

📥

1. Document Ingestion

Multi-source

Connectors for Confluence, Google Docs, Notion, and PDFs via Amazon Textract. Supports incremental updates — only new/changed documents are re-processed. Handles 200+ file formats with metadata extraction.

✂️

2. Semantic Chunking

Context-Aware

Three chunking strategies evaluated — Fixed-size (512 tokens), Recursive Character, and Semantic — with automatic optimization via our /chunk-optimize skill. Preserves semantic boundaries so chunks remain meaningful in isolation.

🔢

3. Vector Embeddings

Dense Retrieval

Each chunk is encoded into a high-dimensional vector using Amazon Titan Embeddings v2 (default) or Cohere Embed-v3. Embeddings capture semantic meaning, enabling "find by concept" rather than exact keyword match. Stored in Amazon OpenSearch with k-NN indexing.

⚡

4. Hybrid Retrieval + Re-ranking

BM25 + Dense

Combines BM25 sparse retrieval (exact keyword precision) with dense semantic search (conceptual similarity) via Reciprocal Rank Fusion. Top-k candidates are re-ranked by a cross-encoder for maximum relevance. Consistently outperforms either method alone.

💬

5. LLM Generation with Citations

Claude on Bedrock

Claude 3.5 Sonnet via Amazon Bedrock generates grounded responses using retrieved context. Every answer includes inline citations linking to source documents. The system refuses to answer when context is insufficient — no hallucinations.

Automation Engine

Powered by Claude Code Skills

The entire RAGixAI pipeline is automated using custom Claude Code slash commands — .md skill files that orchestrate every step from data ingestion to deployment. Zero manual configuration. Zero human bottlenecks.

📥
/ingest-docs
Auto-ingest documents from Confluence, Google Docs, Notion, and PDFs. Handles authentication, pagination, incremental sync, and metadata extraction without manual configuration.
✂️
/chunk-optimize
Automatically tests all three chunking strategies (Fixed 512-token, Recursive Character, Semantic) against your dataset and reports optimal configuration with RAGAS scores.
🔢
/embed-compare
Benchmarks Amazon Titan Embeddings v2, Cohere Embed-v3, and OpenAI text-embedding-3 on your corpus. Reports speed, accuracy, dimensionality, and cost-per-token metrics.
📊
/evaluate-rag
Runs the full RAGAS evaluation suite — Faithfulness, Answer Relevancy, Context Precision, Context Recall, Answer Correctness, Latency — on any pipeline configuration.
🔄
/compare-options
A/B tests multiple RAG configurations in parallel — different chunking strategies, embedding models, retrieval methods, and re-ranking configs — with side-by-side metric comparison.
☁️
/deploy-aws
Deploys the complete RAG pipeline to AWS Bedrock + OpenSearch + Lambda + Step Functions from a single command. Handles IAM roles, VPC config, and environment setup automatically.
📋
/generate-report
Auto-generates a structured evaluation report with charts, metric summaries, configuration comparisons, and recommended optimal setup. Outputs as PDF and HTML.
📡
/monitor-pipeline
Queries live CloudWatch metrics for the deployed pipeline — latency percentiles, retrieval accuracy trends, token usage, cost per query — with anomaly detection alerts.
Philosophy

No Manual Touch Philosophy

From the moment a document enters the system to the moment the pipeline is live in production — everything is orchestrated by Claude Code. This enables:

  • Reproducible experiments (same command = same result)
  • Rapid iteration (reconfigure and re-evaluate in minutes)
  • Peer review of automation logic (skills are version-controlled .md files)
  • Zero deployment drift between development and production
