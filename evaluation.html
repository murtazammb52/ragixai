6 RAGAS Metrics

The Evaluation Framework

RAGAS (Retrieval Augmented Generation Assessment) provides a standardized, automated way to evaluate every component of a RAG pipeline.

🎯

Faithfulness

Range: 0.0 → 1.0 · Higher is better

Measures whether every claim in the generated answer is directly supported by the retrieved context. Prevents hallucinations — the cardinal sin of enterprise RAG.

Faithfulness = |Supported Claims| / |Total Claims|
89%
Target Score
≥ 0.89
❓

Answer Relevancy

Range: 0.0 → 1.0 · Higher is better

Measures how well the answer directly addresses the user's question. High faithfulness but low relevancy means the answer is accurate but off-topic.

Relevancy = avg_cosine_sim(generated_questions, query)
87%
Target Score
≥ 0.87
🎪

Context Precision

Range: 0.0 → 1.0 · Higher is better

Are the retrieved context chunks actually relevant? High precision means few irrelevant chunks are included — the retriever is surgically accurate.

Precision@k = |Relevant chunks in top-k| / k
84%
Target Score
≥ 0.84
🕸️

Context Recall

Range: 0.0 → 1.0 · Higher is better

Did the retriever find ALL the relevant information? Low recall means important context was missed, leading to incomplete answers — even if what was found is accurate.

Recall = |Retrieved relevant| / |All relevant in corpus|
84%
Target Score
≥ 0.84
✅

Answer Correctness

Range: 0.0 → 1.0 · Higher is better

Compares the generated answer against a ground-truth reference answer. The gold standard metric — requires a labeled evaluation dataset with known correct answers.

Correctness = F1(answer, ground_truth)
82%
Target Score
≥ 0.82
⚡

Response Latency

Lower is better · Measured end-to-end

Total time from user query submission to final answer delivery. Enterprise users expect sub-3-second responses. We measure p50, p95, and p99 for a complete picture.

Target: p50 < 1.5s · p95 < 3.0s · p99 < 5.0s

⚙️

Automated Evaluation with /evaluate-rag

The /evaluate-rag Claude Code skill runs the entire RAGAS evaluation suite automatically: ingests EDGAR filings and FinanceBench QA pairs, runs queries through the pipeline, scores all 5 RAGAS metrics, and generates a comparison report — in a single command. No manual scoring. No human bias.
